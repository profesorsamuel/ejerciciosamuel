Cómo usarlo

  1. Selecciona la técnica que quieres preparar.
  2. Completa materia, grado, tema y cantidad.
  3. Pulsa Generar prompt completo y luego Copiar prompt.
  4. Abre ChatGPT u otra IA, pega el prompt y adjunta el PDF de la clase en ese mismo mensaje.
  5. Guarda el banco generado en el formato JSON solicitado y cárgalo en tu plataforma si el juego ya admite ese formato.
Importante: esta página prepara y copia instrucciones; no sube el PDF automáticamente a ChatGPT ni instala por sí sola un motor de juego nuevo. La plataforma debe admitir el tipo de ejercicio y el formato JSON para ejecutarlo.
