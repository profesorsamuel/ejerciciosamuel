CIA - ACTUALIZACIÓN SOLO DE ARCHIVOS MODIFICADOS

1. Abre el ZIP y copia la carpeta ciencias-ia sobre la carpeta ciencias-ia del repositorio GitHub.
   Conserva los archivos que no estén en este ZIP; no borres nada de la raíz.
2. En Supabase (control-notas-jiral), SQL Editor > New query:
   pega el contenido de ciencias-ia/supabase/migrations/CIA_006_importar_matricula.sql y pulsa Run.
3. Configura en la compilación de GitHub Pages las variables VITE_SUPABASE_URL y VITE_SUPABASE_ANON_KEY.
   Nunca publiques claves service_role, secret ni AI_API_KEY.
4. Este proyecto React necesita compilarse con npm install && npm run build desde ciencias-ia.
   No basta abrir el archivo index.html directamente.
5. Al iniciar sesión como profesor, selecciona la plantilla Excel, revisa la vista previa y confirma.

IMPORTANTE: esta entrega solo implementa la importación de matrícula. No incluye aún el generador de preguntas ni las calificaciones.
El SQL usa una RPC pública accesible solo para usuarios autenticados y mantiene la tabla dentro de ciencias_ia.
