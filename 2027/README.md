# CIA – Ciencias IA 2027

Proyecto educativo en construcción. Abrir `index.html` desde GitHub Pages. La versión actual es una demostración local sin conexión segura a Supabase.

## Estructura
- `index.html`: interfaz
- `assets/css/app.css`: estilos
- `assets/js/app.js`: lógica local
- `assets/js/catalogo.js`: catálogo de técnicas
- `assets/js/config.js`: configuración de demostración
- `plantillas/`: CSV
- `sql/`: SQL pendiente; **no ejecutar**

## Limitaciones
Los borradores, los ejercicios y la exportación son para pruebas. No hay autenticación ni registro oficial de notas. Consulte `ESTADO_DESARROLLO.md`.
